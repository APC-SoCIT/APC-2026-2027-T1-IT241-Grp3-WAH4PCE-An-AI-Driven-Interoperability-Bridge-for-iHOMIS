# Documentation Version Control & Branching Strategy

To maintain a clean and reliable documentation history, **`MSYADD1-paper-v1`** serves as the **`main`** branch (Single Source of Truth). All major defense milestones and revision cycles must be branched off accordingly.

---

### Branch Workflow Visualization

```text
(main) MSYADD1-paper-v1
 │
 ├──● [branch] milestone/pre-midterm-defense
 │
 ├──● [branch] revision/adviser-consultation-1
 │
 ├──● [branch] milestone/pre-finals-defense (post-midterm)
 │
 └──● [branch] revision/client-feedback
```

### Additional Notes
Number the files chronologically and have a date inside the Word file to track when the changes were made.
